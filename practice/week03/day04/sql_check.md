## 聚合查询骨架

```sql
SELECT 分组字段,
       COUNT(*) AS 行数,
       ROUND(AVG(数值字段), 2) AS 平均值
FROM 表
WHERE 行级条件
GROUP BY 分组字段
HAVING 组级条件
ORDER BY 排序字段 ASC;
```

注意：不是每个查询都需要 `GROUP BY` 或 `HAVING`；如果查询没有聚合函数，通常不应为了“看起来完整”而分组。
